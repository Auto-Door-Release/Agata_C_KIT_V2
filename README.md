### Электронный модуль Micro Mix&Match V1 для S560

Комплект модернизации для самостоятельной установки в вашу абонентскую трубку **Akuvox S560** в системах IP домофонии, для активации функции "Автовахтер", также известной под другими названиями, такими как: "Автоконсьерж", "Бесконтактное заселение", "Доктор".
