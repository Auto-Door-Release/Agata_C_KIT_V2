# Agata_C_KIT_V2
 Agata_C_KIT_V2 - инструкция по установке электронного модуля


***

### Электронный модуль Agata_C_KIT_V2 для трубки Agata C

Комплект модернизации для самостоятельной установки в вашу абонентскую трубку **Agata C** в системах домофонии **CAME BPT X1 (XiP)**, для активации функции "Автовахтер", также известной под другими названиями, такими как: "Автоконсьерж", "Бесконтактное заселение", "Доктор".


***
### Совместимость
Электронный модуль, конструктивно и функционально, предназначен только для установки в следующие модели абонентских IP аудио устройств:
* **Agata C**
 
Электронный модуль не нарушает штатный режим работы абонентского устройства, при необходимости, вы можете пользоваться домофоном в обычном режиме.

***

### Возможные режимы работы
После установки электронного модуля **Agata_C_KIT_V2** в ваше абонентское устройство **Agata C**, вы можете использовать следующие режимы работы в своем домофоне:
1. Автоматический ответ и открывание двери после первой двойной трели звонка на трубке (примерно через 5 секунд после вызова).
2. Автоматический ответ и открывание двери после трех двойных трели звонка на трубке (примерно через 13-15 секунд после вызова).
3. Секретный режим, открытие после нескольких вызовов, осуществленных в определенный интервал времени. Настраиваемок количество пропускаемых вызовов (от 1 до 4).
4. Штатный режим абонентского устройства, без использования автоматического открывания.

Переключение режимов работы осуществляется при помощи:   
1. Магнита, касанием зоны встроенного магнитного датчика (геркон). 
2. Внешней кнопки, WiFi, Matter или ZigBee реле из вашей экосистемы умного дома.


После каждого короткого, однократного касания магнитом, зоны расположения магнитного датчика - режим работы изменяется на следующий, при этом, абонентское устройство воспроизводит звуковую индикацию, в соответствии с установленным режимом работы.   

Если электронный модуль, находится во втором режиме, третьем или четвертом режиме, то возможно управление через внешнюю кнопку или контакты (тип "сухой контакт") WiFi или ZigBee реле:  
1. Когда контакт управления замкнут - электронный модуль переключается в первый режим работы.. 
2. Когда контакт управления разомкнут - электронный модуль возвращается в тот режим работы, который был выбран до замыкания контактов реле.
